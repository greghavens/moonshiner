# 2026 Volunteer Recognition Luncheon Packet

Use the following level-two sections in exactly this order. Replace all instructions; the final packet must contain no placeholders or drafting notes.

## Event details

State the date, full time range, venue, RSVP deadline, RSVP contact, invitation sender, and master of ceremonies.

## Run of show

Use a Markdown table with these columns: `Start | End | Minutes | Component | Owner`. Use 24-hour `HH:MM` times.

## Recognition roll

Use a Markdown table with these columns: `Order | Name | Distinction | Citation`.

## Staff assignment checklist

Use one unchecked Markdown task-list item per recorded staff member. Each item must name the person and state all of that person’s recorded duties.

## Invitation email

Give the subject on a `Subject:` line, then a send-ready body of 120–150 words. Count the greeting and sign-off in the body; do not count the subject line.
