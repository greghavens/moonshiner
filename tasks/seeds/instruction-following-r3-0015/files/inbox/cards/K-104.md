# K-104 — Error Log as Question Bank

Collection: Learning
Status: active
Captured: 2026-04-02
Source: Weekly review 2026-04-02

## Core idea

Turn each meaningful error into a prompt, record its cause and corrected rule, and retry it during the next weekly review.

## Context

The log is most useful when it generates another attempt. Merely cataloging mistakes created a record but did not test whether the correction held.

## Connection cues

- K-104 → K-102 — Put corrected errors back onto the review schedule.

## Review action

Convert the two newest errors into answerable prompts and schedule them.
