## Core idea

Start with review gaps of 1, 3, 7, and 14 days, shortening the next gap after a miss; this is a personal starting heuristic, not a universal rule.

## Context

The cadence is a planning aid for this notebook, not a claim about an optimal schedule for every learner or topic. A failed retrieval returns the item to a shorter interval.
