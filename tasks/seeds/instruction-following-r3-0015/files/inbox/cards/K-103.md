# K-103 — Interleave Similar Problem Types

Collection: Learning
Status: active
Captured: 2026-03-18
Source: Course debrief week 6

## Core idea

After initial worked examples, mix similar problem types so practice includes choosing the method as well as executing it.

## Context

Blocked sets made procedures feel fluent but hid confusion about which procedure applied. A mixed set exposed weak cue selection.

## Connection cues

- K-103 → K-105 — Use explanation to expose weak problem-type discrimination.

## Review action

Build one six-question set that alternates among three problem types.
