# Local hospitality registry

`./hospitalityctl` is the executable interface to this sandbox's saved profile,
availability service, hospitality records, and notifications. Start with
`./hospitalityctl --help`; each subcommand also supports `--help`.

The files below `.hospitality/` are private service storage and audit evidence,
not an alternate interface. The files below `.harness/` are protected
verification material. Use neither directory directly.
